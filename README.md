# YACE (Yet Another Canvas Extension)

> **YACE** — *Yet Another Canvas Extension*

A power-user browser extension that scrapes module-embedded files, unifies Gradescope deadlines, and replaces the native Canvas sidebar with a cyber-deck HUD.

## Features
- **Unified Timeline:** Canvas + Gradescope merged into a single schedule.
- **Weekly Progress HUD:** Tracks Monday-to-Sunday completion with confetti milestones.
- **In-Tab Document Viewer:** Fast-preview assignment PDFs without cluttering your downloads folder.
- **Gradescope Direct Actions:** One-click launch to the Gradescope submission drawer.
- **Vim / Power-User Navigation:** Navigate via `j`/`k`, toggle done with `x`, view files with `v`, and search with `/`.
- **Smart Title Cleanup:** Module-file titles like `RevisedA2.pdf` or `Lab_01_v2_FINAL.docx` are auto-cleaned into readable names.
- **Pin to Top:** Star ⭐ any assignment to force it to the top of every list, regardless of due date.
- **Announcements Tab:** Pulls Canvas course announcements and the unread inbox count, with a neon alert pill for anything new.
- **Minimize to Edge:** Collapse the whole HUD to a slim arrow tab on the screen edge, and slide it back out with one click.
