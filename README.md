# Canvas & Gradescope Unified Tasks

A Firefox extension that automatically scrapes Canvas modules and Gradescope assignments to display a consolidated task dashboard.

## Features
- Scrapes homework and PDFs without formal Canvas due dates.
- Direct sync with Gradescope Fall 2026 courses.
- Task completion persistence and duplicate detection.
- Dynamic completion progress bar with milestone visual tiers, shimmer effects, and celebratory confetti bursts upon hitting 100%.

## How to Install (Temporary Add-on in Firefox)
1. Clone or download this repository as a `.zip` and extract it.
2. Open Firefox and navigate to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on...** and select `manifest.json`.
4. Navigate to Canvas (`mycourses.unh.edu`) to see the dashboard.
